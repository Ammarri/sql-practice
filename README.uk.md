# SQL Practice — T-SQL / MS SQL Server
 
[English version](README.md)
 
Цей репозиторій містить самостійну практику з T-SQL, не курсові завдання.
Мета — напрацьовувати володіння SQL по мірі проходження тем і вести робочий облік того, що вже пройдено.
Це не основний репозиторій-портфоліо: готові до презентації проєкти лежать в окремому репозиторії.
 
## Бази даних:
 
- **Northwind** — вигадана торговельна компанія (клієнти, замовлення, товари, постачальники, співробітники, доставка).
- **pubs** — вигадане видавництво (книги, автори, видавці, продажі).
- **AdventureWorks2025** — велика виробнича компанія (велосипеди): продажі, виробництво, закупівлі, HR. 70+ таблиць, для просунутої практики.
- **WideWorldImporters** — сучасна торговельна компанія-імпортер зі свіжою структурою, добре підходить для CTE і віконних функцій.

## Рівні складності
 
Залишено для довідки — не строга рубрика.
 
| Рівень | Охоплює |
|---|---|
| Базовий | SELECT, обчислювані стовпці, WHERE, агрегати (без JOIN, без групування) |
| Проміжний | GROUP BY / HAVING, JOIN, підзапити, робота з NULL |
| Просунутий | Багатоумовна бізнес-логіка, крайні випадки, патерни з урахуванням продуктивності |
